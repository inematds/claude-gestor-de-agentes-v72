Aula 3 · 15 min

Segundo plano: várias sessões trabalhando, uma tela para ver todas

Até aqui, cada tarefa prendia você na frente da conversa. Com o segundo plano, você dispara uma sessão, libera o terminal e ela segue trabalhando. A agent view junta todas numa tela só e põe no topo as que precisam de você. Nesta aula você manda duas tarefas leves para o segundo plano e aprende a entrar, espiar e parar cada uma.

Objetivo: Mandar tarefas para o segundo plano com claude --bg e acompanhar todas na agent view.

01 · O caminho de uma sessão em segundo plano

Toque ou clique em cada etapa.

Aula 301 · O caminho de uma sessão em segundo planoToque ou clique em cada etapa.

1/5

Pedido

Você escreve claude --bg e o pedido entre aspas, com a flag (uma opção que começa com dois tracinhos, como --bg) antes do pedido. Com --name a sessão ganha um nome fácil de achar. Se você já está dentro de uma sessão, a seta ← no prompt vazio ou o comando /background manda essa sessão para o segundo plano.

Role a página: cada etapa abaixo acende a sua parte do diagrama.

  1. 1/5

    Pedido

    Você escreve claude --bg e o pedido entre aspas, com a flag (uma opção que começa com dois tracinhos, como --bg) antes do pedido. Com --name a sessão ganha um nome fácil de achar. Se você já está dentro de uma sessão, a seta ← no prompt vazio ou o comando /background manda essa sessão para o segundo plano.

  2. 2/5

    Supervisor

    Cada sessão roda dentro de um processo supervisor, um programa que fica cuidando delas por baixo. Por isso dá para fechar a janela e o terminal: o trabalho continua, desde que o computador esteja ligado.

  3. 3/5

    Agent view

    Uma tela com todas as sessões em segundo plano, separadas em grupos. As que precisam de você ficam no topo. Há também o grupo Pinned, com as que você fixou. O terminal avisa quando uma sessão precisa de você, termina ou falha.

  4. 4/5

    Você age

    Enter numa linha abre a sessão (attach) e mostra um resumo do que aconteceu enquanto você estava fora. ← no prompt vazio ou /exit volta para a lista. Pelo terminal: claude logs mostra a saída recente sem entrar, e claude stop para a sessão.

  5. 5/5

    De uma conversa para várias

    Várias sessões trabalhando ao mesmo tempo e uma tela que diz qual precisa de você. É o primeiro passo para gerir, em vez de acompanhar cada resposta.

Você dispara, o supervisor segura, a agent view mostra e você só entra onde é preciso.

02 · Na prática, com a agência da Ana

Ana tem uma agência pequena com três clientes: uma padaria, uma clínica e uma loja de roupas.

1. Despachar

Despachar é mandar uma tarefa para uma sessão em segundo plano. Uma sessão é uma conversa do Claude com o seu próprio histórico.

Segunda de manhã, a Ana abre o terminal na pasta da padaria e manda um claude --bg pedindo o relatório semanal. Na pasta da clínica, outro pedindo os posts da semana. Em dez segundos as duas estão trabalhando e o terminal está livre.

Dê nomeCom --name padaria-relatorio a Ana acha a sessão pelo nome, e não por um código como 7c5dcf5d.

2. Ler a tela

claude agents abre a agent view. Os grupos estão em inglês: Needs input (precisa de você), Working (trabalhando), Ready for review (pronto para revisar) e Completed (terminadas, falhas e paradas).

Ready for review é para quem programa: aparece quando a sessão abriu um PR (pull request, um pedido de revisão de código no GitHub) que espera revisão ou tem testes falhando. Quem não programa raramente vê esse grupo.

Na caixa de texto da tela dá para filtrar: s:blocked mostra tudo que espera você, s:working só as que estão rodando e n:padaria procura pelo nome.

AtalhosCtrl+T fixa uma sessão no topo (Pinned). Ctrl+S agrupa por pasta. claude agents --cwd [pasta] mostra só um projeto.

3. Entrar e voltar

A sessão dos posts da clínica está em Needs input porque pediu permissão: antes de rodar um comando ou mexer num arquivo, o Claude pergunta se pode. A Ana tecla Enter nela (attach), vê um resumo do que a sessão fez e a pergunta parada, e responde sim (ou não).

Ela responde e tecla ← no prompt vazio para voltar à lista. A sessão segue trabalhando sozinha. Para só espiar, sem entrar, existe claude logs; para encerrar, claude stop.

Regra de bolsoEntre só onde a tela pede. O resto você olha no fim, já pronto.

4. Os limites

A agent view é uma prévia de pesquisa (research preview) desde maio de 2026: pode mudar. As sessões rodam no seu computador, então ele precisa ficar ligado. --bg não combina com -p, o modo "imprime e sai" do Claude Code: uma pergunta, uma resposta, sem conversa.

Subagentes (ajudantes que uma sessão cria por dentro para uma parte do trabalho) e colegas de time não aparecem como linhas separadas. Sem terminal, no app Desktop (aba Code): + New ou Ctrl+N abre outra sessão, Ctrl+Tab troca entre elas, e o sistema avisa quando uma termina.

Confira a sua versãoRode claude --version. Este curso conferiu os comandos na versão 2.1.312.

03 · Os comandos do segundo plano

Troque o texto entre < > pelo seu. A flag --bg vem antes do pedido. Os dois pedidos só leem: funcionam em qualquer pasta e não mudam nada.

Terminal · despachar duas sessões leves
# cd = entrar numa pasta. Troque o caminho pelo de uma pasta sua.
# Para achar o caminho: arraste a pasta para a janela do terminal e ele aparece escrito.
# No Windows, também dá para clicar na barra de endereço do Explorador e copiar.
cd <caminho-da-pasta>
claude --bg --name o-que-tem-aqui "Liste os arquivos desta pasta e diga em 3 linhas o que tem aqui. Só leia, não altere nada."
claude --bg --name contar-arquivos "Diga quantos arquivos há nesta pasta e quais são os 3 maiores. Só leia, não altere nada."
Terminal · acompanhar, entrar, espiar e parar
claude agents            # abre a agent view
claude agents --json     # o mesmo estado em JSON (texto organizado em campos, que programas leem)
claude attach <id>       # entra na sessão
claude logs <id>         # mostra a saída recente sem entrar
claude stop <id>         # para a sessão
Na caixa da agent view · filtros
s:blocked
s:working
n:contar
Simulação: exemplo ilustrativo
backgrounded · 7c5dcf5d · o-que-tem-aqui
  claude agents            lista as sessões
  claude attach 7c5dcf5d   abre no terminal
  claude logs 7c5dcf5d     saída recente
  claude stop 7c5dcf5d     para a sessão
Needs input (1)
  contar-arquivos  pede permissão para listar a pasta
Working (1)
  o-que-tem-aqui   lendo os arquivos da pasta
Completed (0)

Needs input por permissão: o Claude pergunta antes de rodar um comando ou mexer num arquivo. Entre na sessão (Enter) e responda sim para ela seguir.

  • Enter ou →: entra na sessão (attach) e mostra o resumo do que ela fez.
  • ← no prompt vazio ou /exit: volta para a lista.
  • Ctrl+T: fixa no topo. Ctrl+S: agrupa por pasta.
  • /model, /effort e /fast digitados na caixa valem para as próximas sessões despachadas.

05 · Prática: duas sessões em segundo plano

Use tarefas só de leitura. Assim nada muda nos seus arquivos.

E1 · Despachar duas

10 min

Abra o terminal. Entre numa pasta sua com cd (o comentário do bloco mostra como achar o caminho) e rode as duas linhas com --bg e --name do primeiro bloco. Depois rode claude agents --json, que mostra o estado em JSON: texto organizado em campos, que programas leem.

Pronto quando: a saída do claude agents --json cita os dois nomes que você deu (o-que-tem-aqui e contar-arquivos).

E2 · Entrar e voltar

5 min

Abra claude agents, tecle Enter numa das sessões, leia o resumo do que ela fez e volte com ← no prompt vazio.

Pronto quando: você está de volta na agent view e a sessão em que entrou continua listada.

E3 · Sem terminal (app Desktop)

10 min

Na aba Code do app Desktop, abra duas sessões com + New (Ctrl+N), mande um dos pedidos acima em cada uma e troque entre elas com Ctrl+Tab enquanto trabalham.

Pronto quando: as duas sessões responderam e você recebeu o aviso do sistema quando uma terminou.
